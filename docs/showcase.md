# Showcase: agent-built games and how they were made

Notable games built mostly by coding agents, with the posts and write-ups where their creators explain the process. Most links go to X posts; the replies often hold the details. Collected in October 2026.

## Discussions and guides

- [10 repos for building AAA-style games with agents](https://x.com/heyrimsha/status/2115738391467946090) and [10 agent game-dev repos](https://x.com/heyrimsha/status/2110321800936866244), by Rimsha Bhardwaj. The replies add many more tools (meshoptimizer, Jolt in Godot, Dear ImGui debug panels, Effekseer VFX packs).
- [Dan Greenheck's Tidewater prompt list](https://x.com/dangreenheck/status/2102911556296052788): the clearest public example of directing an agent through a high-end visual project.
- [Godot is well suited for game development with AI coding agents](https://dev.to/abagames/godot-is-well-suited-for-game-development-with-ai-coding-agents-2lcm): why text scene files and a CLI make Godot agent-friendly.
- [AI 3D game dev tutorial](https://youmind.com/landing/x-viral-articles/ai-3d-game-dev-tutorial): PRD → reference images → Tripo → Blender rigging → Mixamo → Unity MCP, with a reviewer agent comparing screenshots against references.
- [Claude-Code-Game-Studios](https://github.com/Donchitos/Claude-Code-Game-Studios): a 49-agent "studio" whose own test found that a one-page brief beat 30 design documents.
- [godogen](https://github.com/htdt/godogen): describe a game and the agent writes code, generates assets, runs the engine and checks the result.
